**ls**: listar

**cd**: change director

**cd ..**:change director para la carpeta anterior

-**mkdir**: crear una carpeta

-**touhc**: crear archivos

-**git init**: iniciar git en una carpeta nueva

-**git add** primer paso para guardar los archivos

-**git commit -m** crear y guardar el commit con el tiempo

-**git status** ver el estado de los archivos

-**git push** subir el archivo al github

-**git remote add origin** enlazar con el repositorio

-**rm**: remover  y se añade *-r* para un eliminado recursivo
